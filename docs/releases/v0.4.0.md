EarthGlass serves geospatial information independent of the renderer, through an API and a CLI, with a bundled GeoNames city index and explicit freshness states.

**Pre-release.** First tagged release of a working project. An engineering tool for demonstration and controlled local use.

### What it does
- A local API and `earthglass` CLI for geospatial queries over provider data.
- A bundled GeoNames city index, so it works with no network for the quick start.
- Freshness states that say when data is current, stale or unavailable (see `docs/FRESHNESS.md`).

### Verified
- 137 automated tests pass in CI (2 skipped).
- The wheel installs in a clean environment and the `earthglass` command runs.

### Known limits
- Live provider data needs network access and the provider's own terms.
- The desktop client (`obeos-earth`) is not part of this wheel unless built with `EARTHGLASS_BUNDLE_DESKTOP=1`.
- Limits on data freshness are listed in `docs/FRESHNESS.md`.

Checksums are in `SHA256SUMS`. See the [changelog](https://github.com/5K-bit/Earthglass/blob/v0.4.0/CHANGELOG.md) for details.
